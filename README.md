# nse-stock-agent
# 📈 NSE Stock Technical Engine (No API Key Required)

A zero-cost technical analysis tool for Indian stock market equities (**NSE**) built with **Streamlit**, **yfinance**, and **Plotly**.

## 🚀 How to Deploy on Streamlit Cloud (100% Free)

1. Push this project to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io/) and click **New App**.
3. Select your repository and set the **Main file path** to `app.py`.
4. Click **Deploy**! (No environment variables or secrets required).
